# `valibot-form-data` CHANGELOG

This is the changelog for [`valibot-form-data`](https://github.com/typed-web/typed-web/tree/main/packages/valibot-form-data). It follows [semantic versioning](https://semver.org/).

## v0.2.0 (2025-12-29)

- Add `preprocessFormData` as a public export for preprocessing form data to nested objects
- Add plain object support to `formData` validator (in addition to FormData and URLSearchParams)
- Refactor validators (text, numeric, checkbox, file, repeatable) to follow Valibot's official schema structure pattern
- Improve TypeScript type inference throughout the library

## v0.1.1 (2025-10-29)

- Update package metadata and documentation

## v0.1.0 (2025-10-29)

- Initial release of `@typed-web/valibot-form-data`
